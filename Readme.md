# 📱 Ajit Demo (Android Jetpack Compose App)

This is a modern Android application built using **Jetpack Compose**, following **Clean Architecture** principles. It features modular layers, dependency injection with **Koin**, and data fetching via **Retrofit**.

---

## 🚀 Features

- ✅ Jetpack Compose UI
- ✅ Clean Architecture (Presentation, Domain, Data layers)
- ✅ MVVM Pattern
- ✅ Retrofit for REST API integration
- ✅ Koin for Dependency Injection
- ✅ State Management (Loading, Success, Error)
- ✅ Portfolio and Holdings screen with real-time P&L calculations
- ✅ Extension functions for formatting and rounding values
- ✅ Modularized and scalable codebase

---
## 🛠️ Tech Stack

| Tool/Library        | Purpose                          |
|---------------------|----------------------------------|
| Jetpack Compose     | Declarative UI Framework         |
| Kotlin              | Main programming language        |
| Retrofit            | Networking and API calls         |
| Koin                | Dependency Injection             |
| Coroutines/Flow     | Asynchronous & reactive streams  |
| ViewModel + State   | MVVM & reactive UI updates       |
